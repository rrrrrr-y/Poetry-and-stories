# Poetry-and-stories

思念，情绪，以及日记。 
写给R。

2026年9月5日：
写给特定的人，也写给自己。
如果不巧被你看到——
请当作不小心翻到了一本合上的笔记本。

这里存放的是：
我无法安放的思念与焦虑，如果你也想念我的话，也是我写给你的我自己，你或许会感到熟悉。
仅此而已。
顺利，克制，渡过。

此外，如果我可以爱的话，就用这个记录爱。
有的角色就是会忍不住让人心疼和永远也不想离开。
才发现方式不对的相爱会撞得头破血流。
不知道是否需要，那么就留在这里吧；
不知道可不可以去爱，那么就默默存在；
以后的以后，只想简单。
也不知道会怎么发展，但我想伤害彼此不是R和Y的本意。尽管我们都很疼痛。

Will you ?
